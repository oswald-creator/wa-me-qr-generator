How it works

  1. Scan — the person's phone camera reads the code and opens the link.
  2. Chat opens — WhatsApp opens a conversation with your number. No contact needs to be saved first.
  3. Message ready — your pre-filled text is already typed in. They review it and tap send.

Under the hood it's one link: https://wa.me/<number>?text=<message>. The number is digits only, country code first; the message is URL-encoded automatically by this tool.

Printing tips

  • Size: at least 2 × 2 cm (about ¾ inch) for handouts; bigger for posters people scan from a distance — roughly 1 cm of QR per 10 cm of scanning distance.
  • Contrast: black code on white, with the white border (quiet zone) kept intact. Don't invert the colours.
  • Finish: matte, not glossy — glare defeats phone cameras.
  • One code per purpose: a different pre-fill or placement tag for the foyer poster, the table card and the website, so replies tell you what worked.
  • Test first: print one copy, scan it with a different phone, and confirm the right number, profile and message appear.

Good to know

  • Personal vs business: the code is identical either way — what changes is the profile the scanner lands on. Business accounts add hours, location, a catalogue and greeting messages.
  • Changing your mind: a printed code always points to the number baked into it. If the number changes, print new codes — old ones can't be redirected.
  • Never share a pairing code: the QR WhatsApp shows for linking a new device or WhatsApp Web is a different, private code. Never print or post that one.
  • No tracking: WhatsApp reports no scan counts on wa.me links — the placement tag is the simple way to tell your signs apart.
